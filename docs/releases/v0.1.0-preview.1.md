# PromiseProof v0.1.0-preview.1

An installable development preview of the local deterministic outcome-verification CLI. The package version is 0.1.0 and the provisional package name is promiseproof-local. Distribution is through this GitHub release; npm registry publication and stable package branding remain pending.

## Install and run

Requires Node.js 22.12 or newer, npm and Chromium. Download `promiseproof-local-0.1.0.tgz` and `SHA256SUMS.txt` from the release assets. Compare the tarball's SHA-256 against the checksum file before installing. The checksum detects transfer differences; it is not a signature or third-party attestation.

In a new test-project directory:

```sh
npm init -y
npm install /absolute/path/to/promiseproof-local-0.1.0.tgz
npm exec playwright install chromium
node node_modules/promiseproof-local/examples/server.mjs
```

Use your downloaded file's actual path. Keep the synthetic loopback fixture running on http://127.0.0.1:4173. On Linux, browser installation may need `--with-deps chromium`.

In a second terminal in the same test-project directory:

```sh
npm exec --offline -- promiseproof init
npm exec --offline -- promiseproof doctor --spec node_modules/promiseproof-local/examples/simple-form/spec.json
npm exec --offline -- promiseproof verify node_modules/promiseproof-local/examples/simple-form/spec.json
npm exec --offline -- promiseproof verify node_modules/promiseproof-local/examples/failing-workflow/spec.json
npm exec --offline -- promiseproof verify node_modules/promiseproof-local/examples/invitation-flow/spec.json
```

Verification exits are 0 / 1 / 0. The failing form claims UI success but does not persist the record; retain its failed criterion. Doctor readiness is setup-only. Open each printed report path in a browser and keep the whole bundle with its images/traces. Next check/Next steps suggests investigations from recorded evidence without changing the verdict.

## Included

Versioned JSON specs and policy, real Chromium/UI/test-API checks, isolated sessions, four verdict states, local JSON/offline HTML evidence, genuine passing/failing/invitation examples, setup diagnostics and coding-agent instructions. Malformed input contents are withheld from CLI parser errors.
