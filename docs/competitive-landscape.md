# Competitive landscape

Primary repositories and documentation reviewed on 2026-10-13. These are capability observations from published sources, not hands-on comparative benchmarks. Do not claim that competitors cannot implement outcome verification.

| Project                                                                                  | What it already solves                                                                                                                                                                                                                      | Implication for this MVP                                                                                                                 |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| [Playwright / Playwright Test](https://playwright.dev/docs/test-assertions)              | Browser automation, retrying web assertions, test runner and fixtures. [Context tracing](https://playwright.dev/docs/api/class-tracing) captures browser operations and network activity; custom assertion verdicts need their own records. | Reuse actions/assertions/traces. Do not build a browser protocol, locator engine, trace viewer or general test framework.                |
| [ProofShot](https://github.com/AmElmo/proofshot)                                         | Agent-oriented browser recording, screenshots, error collection and artifact bundles for human review.                                                                                                                                      | Recording alone is not differentiation. Add explicit programmatic outcome verdicts and dependency-aware missing-evidence behavior.       |
| [OpenUser](https://github.com/manalkaff/openuser)                                        | Self-hosted persona-oriented testing through coding agents, local browser/daemon, findings and dashboard. Its service does not require an additional model API key.                                                                         | Do not claim exclusive local-first or coding-agent support. Defer personas, SQLite history, daemon/dashboard and subjective UX findings. |
| [Stagehand](https://github.com/browserbase/stagehand)                                    | AI-assisted web interaction/extraction; [local and remote environments](https://github.com/browserbase/stagehand/blob/main/packages/docs/v3/references/stagehand.mdx) with configurable models.                                             | Do not rebuild natural-language browser navigation. Planning belongs to the user's existing agent; fixed specs belong to the runner.     |
| [Browser Use](https://github.com/browser-use/browser-use)                                | Model-driven browser agents with existing automation infrastructure.                                                                                                                                                                        | Defer autonomous exploration, a model-provider abstraction and a general browser agent platform.                                         |
| [Existing PromiseProof](https://github.com/AlexPaiva/PromiseProof/blob/main/ADOPTION.md) | An independent project already uses this name for deterministic evaluation of supplied evidence around a narrow personalization promise.                                                                                                    | Public branding is unresolved. Preserve the working name locally; do not imply affiliation or a unique name.                             |

The proposed value here is a small review contract around a software outcome: explicit assertions, actual browser execution, controlled independent API reads, action-bound responses, isolated users, dependency-aware NOT_VERIFIED states and one portable offline bundle. A developer can inspect the same spec the runner executed and see that UI success did not establish backend persistence.

This is a product hypothesis: developers using coding agents may prefer a compact declarative outcome contract and reviewer-oriented report over composing those parts in individual Playwright scripts. It has not been validated through adoption, revenue or interviews. Playwright can reproduce these behaviors with custom tests/reporters; PromiseProof earns its installation by packaging a consistent workflow and evidence semantics.

Removed/deferred redundant scope: browser engine, visual trace player, selector self-healing, video platform, hosted dashboard, persona engine, generic agent orchestration and paid model integrations. No unsupported competitive rankings, user counts or efficacy claims are made.
