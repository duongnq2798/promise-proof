# Security policy

This is a 0.1 development preview. There is no production service or security SLA. Use authorized test environments and review [security boundaries](docs/security.md).

Do not open public issues containing credentials, private screenshots, traces, raw tokens or exploitable live targets. Use [GitHub private vulnerability reporting](https://github.com/duongnq2798/promise-proof/security/advisories/new), enabled for this repository. A dedicated email contact and response SLA have not been established.

Provide version, platform, a minimal synthetic reproducer, expected boundary, observed violation and sanitized evidence. Keep sensitive bundles local until a private channel is agreed.
